4.
throw is used inside a method to actually throw an exception object.
throws is used in a method signature to declare the exception that a method might throw.
import java.io.*;

public class ThrowThrowsExample {

    // Method declares it may throw IOException
    public static void readFile(String filename) throws IOException {
        File file = new File(filename);
        if (!file.exists()) {
            // Actually throws an exception
            throw new IOException("File not found: " + filename);
        }
        System.out.println("File exists!");
    }

    public static void main(String[] args) {
        try {
            readFile("nonexistent.txt");
        } catch (IOException e) {
            System.out.println("Caught exception: " + e.getMessage());
        }
    }
}

8.
Aspect	Aggregation	Composition
Relationship Type	“Has-a” (weak relationship)	“Part-of” / strong ownership
Lifecycle	Independent; child can exist without parent	Dependent; child’s lifecycle is tied to parent
Object Creation Location	Child object can be created outside parent and passed in	Parent creates and owns child object
UML Symbol	Hollow diamond	Filled (black) diamond
Example	School has Teacher (a teacher can exist without a school)	House has Room (a room cannot exist without the house)

Aggregation = weak association, child can live independently.
Composition = strong ownership, child cannot exist without parent.
